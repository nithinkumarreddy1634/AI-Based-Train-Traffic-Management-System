# Data Directory (`data/`)

This directory will store sample datasets, railway section network schemas, static timetable schedules, and test scenario definitions.

## Planned Contents
- `networks/`: Network topology graph definitions (stations, block sections, signals, crossovers).
- `schedules/`: Standard train timetables, priorities, train lengths, and locomotive categories.
- `scenarios/`: Benchmark scenarios (peak hour traffic, single track bottle-neck, signal disruption).
