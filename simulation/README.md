# Train Traffic Simulation Module (`simulation/`)

This directory is reserved for Phase 2 discrete-event simulation of railway section dynamics.

## Planned Scope
- **Discrete-Event Clock**: Simulating train movements across discrete railway blocks and signaling sections.
- **Section Kinematics**: Train acceleration, cruising, deceleration, and braking profiles.
- **Conflict & Incident Ingestion**: Injecting simulated track maintenance, temporary speed restrictions, signal failures, and unexpected halts.

*Note: Phase 1 provides foundation only; simulation engines will be implemented in Phase 2.*
